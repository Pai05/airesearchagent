════════════════════════════════════════════════════════════════════════════════
                        TROUBLESHOOTING QUICK REFERENCE
════════════════════════════════════════════════════════════════════════════════

PROBLEM: Backend returns 502
SOLUTION:
  1. Check Render logs (Dashboard → Logs)
  2. Verify all 10 env vars are set
  3. Ensure serviceAccountKey.json is uploaded
  4. Try: Settings → Restart Instance

PROBLEM: "Could not reach backend"
SOLUTION:
  1. Verify Render URL in vercel.json is correct
  2. Check CORS_ORIGINS env var matches Vercel domain
  3. Run: python test_backend_connectivity.py <url>
  4. Check browser network tab for actual error

PROBLEM: Gemini extraction fails
SOLUTION:
  1. Check GEMINI_API_KEY is valid
  2. Check API quota hasn't exceeded
  3. Backend automatically falls back to mock
  4. Remove key if not using (optional)

PROBLEM: Firebase auth doesn't work
SOLUTION:
  1. Verify all FIREBASE_* env vars
  2. Download fresh serviceAccountKey.json
  3. Check that key file is readable
